# samples

**Synthetic only.** Every program, copybook and data file here was written for the Diocle hackathon project for a fictional bank. Nothing is derived from any real system, employer or client.

| Sample | What it is |
|---|---|
| [`interest-accrual/`](interest-accrual/) | `INTACCR` batch program: daily interest accrual and maintenance fee, with planted legacy traps (half-away-from-zero rounding, truncation, silent high-order overflow). Includes a hand-written naive Java conversion (`java-conversion/`) for the "bring your own conversion" mode. `sample.json` lists the DD names, record layouts and traps. |

Build and run the COBOL directly (GnuCOBOL 3.x):

```sh
cd samples/interest-accrual
cobc -x -std=ibm -I copybooks -o /tmp/intaccr src/INTACCR.cbl
DD_ACCTIN=accounts.dat DD_INTOUT=results.dat /tmp/intaccr
```

Input files are generated by the verifier, not committed.
