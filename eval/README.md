# Frozen evaluation on unseen programs

> **SYNTHETIC.** Written for the Diocle hackathon project.

`unseen/` holds four COBOL programs written after the implementation was frozen (git tag `eval-freeze-1`) and committed before any model run, so nothing in Diocle was tuned to them. `samples/` is what the analyzer derived from them, unchanged. The protocol and results are in [docs/EVALUATION.md](../docs/EVALUATION.md).
