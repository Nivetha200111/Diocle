# Where Meta models are used

Every model call in the product goes to a Meta model: Muse Spark through the Meta Model API, or Muse Spark Open through a partner host. No other LLM is called by the product (the `openai` Python package is used only as an OpenAI-compatible HTTP client; its base URLs come from `.env` and point at Meta or the partner host, never at an OpenAI model). Model IDs, endpoints and keys come from `.env` (see `.env.example`), not from code. The development tooling that helped write the code (Claude Code) is separate and not part of the product.

Counts below are from the public run list (`GET https://diocle.vercel.app/api/runs` and each run's `usage.modelCalls`, read Nov 3, 2026: 83 runs; 71 translated by Muse Spark, 11 by Muse Spark Open, 1 with no model recorded). Costs are estimates from list prices.

## Who decides what

Translator writes Java. Repair agent uses tools to address mismatches the comparison observed. Breaker designs targeted inputs after the ordinary check passes. Deterministic execution (GnuCOBOL and the JVM, byte comparison) decides whether outputs match; no model does. Not every run uses every model or agent: each run page lists its logged calls. Roles below with thin evidence (cross-check, guard review) are not counted as established reliability improvements.

**One concrete input that changed an outcome:** in run `chqclr-20261028-214355`, Muse Spark as breaker designed `RACCT00000200000008NS 1000YYYYYYYYYYYYYY`, giving the reason "Fee with leading space is zero in Java but may be nonzero in COBOL." Run through both: COBOL on GnuCOBOL fee `20.00`, Java `0.00`. Certification was withdrawn until the repair agent fixed it. The record is malformed; see [SHOWCASE_CHQCLR.md](SHOWCASE_CHQCLR.md).

## Not Meta models, and why they are disclosed

- The demo video narration is the author's own recorded voice; no speech synthesis is used in the video. See [HACKATHON_COMPLIANCE.md](HACKATHON_COMPLIANCE.md).
- The two spoken-question clips in the product are the author's own recorded voice (`services/api/diocle_api/voice_clips/`).
- GnuCOBOL is the verifier's oracle and is not a model.
